Landing page premium diseñada para agencias de marketing y servicios digitales, enfocada en la conversión máxima a través de **Psicología de Ventas**, **Copywriting Científico** y una **Experiencia de Usuario (Onyx & Ember)** impecable.

## 🚀 Características Principales

- **Arquitectura de Conversión:** Estructura probada para guiar al usuario desde el dolor hasta la solución (ROI).
- **Diseño Onyx & Ember:** Estética oscura premium con acentos vibrantes, micro-animaciones y efectos de vidrio (Glassmorphism).
- **Performance Extrema:** 100/100 en SEO y 90/100 en Accesibilidad (WCAG compliant).
- **Interactividad Galardonada:** 
  - Scroll suave con **Lenis**.
  - Animaciones de alta performance con **GSAP**.
  - Calculadora de ROI dinámica e interactiva.
  - Cursor magnético personalizado.

## 🛠️ Stack Tecnológico

- **Frontend:** React 18
- **Estilos:** Tailwind CSS v3 (Custom Onyx Design System)
- **Animaciones:** GSAP + Framer Motion
- **Iconografía:** Lucide React
- **Hosting:** Optimizado para Vercel/Netlify

## 📦 Instalación y Desarrollo

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/landing-agency.git
   ```
2. Instalar dependencias:
   ```bash
   npm install
   ```
3. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```
